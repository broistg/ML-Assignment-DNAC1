Adult Census Income

Determine if a person earns more than $50K per year using demographic and occupational features

1. Exploratory Data Analysis

Dataset Overview

Adult Census Income Dataset contains demographic and occupational information from the 1994 U.S. Census database. Each record includes personal, employment, and economic attributes.

  • 48,842 instances × 14 attributes
  • Income labels: <=50K or >50K
  • Numerical features: age, fnlwgt, education-num, capital-gain, capital-loss, hours-per-week
  • Categorical features: workclass, education, marital-status, occupation, relationship, race, sex, native-country

Income Distribution

The dataset shows a clearly imbalanced distribution of income labels, with the <=50K class being significantly more frequent than the >50K class.

Numerical Features

Numerical features such as capital-gain and fnlwgt are highly skewed.

Categorical Features

Categorical features like education, occupation have a large number of unique categories.

2. Data Preprocessing

Handling Missing Values

  • Numerical features: Handled using median, mean, or constant strategies.
  • Categorical features: Filled using most_frequent or constant strategies.

Encoding & Scaling

  • One-Hot Encoding: For nominal categorical features.
  • Ordinal Encoding: For ordinal features (e.g., education level).
  • Standard/Min-Max Scaling: applied to numerical features.

Dimensionality Reduction

Principal Component Analysis (PCA) applied to reduce dimensionality while retaining 90% or 95% of the variance.

Key Findings

  • TabNet achieved the highest overall F1-score, outperforming traditional ML models.
  • Logistic Regression and SVM were the best performers among traditional models (F1 ~0.65).
  • PCA retaining 95% variance consistently performed better than 90%.
  • Deep learning models generally outperform traditional ML when sufficient data and preprocessing are applied.

4. Conclusion

  • Deep learning models tend to achieve higher predictive performance on complex tabular data, especially when nonlinear interactions exist.
  • Proper preprocessing (scaling, imputation) significantly impacts model performance.
  • TabNet is recommended when leveraging deep learning for tabular datasets.
