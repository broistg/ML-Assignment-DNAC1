Project Summary

This repository contains assignments for the Machine Learning course (CO3117). The goal is to build end-to-end pipelines for different data modalities using both traditional ML and deep learning approaches.

Learning Objectives

  • Design reproducible data preprocessing and feature engineering pipelines.
  • Train, evaluate, and compare traditional and deep-learning models.
  • Work with tabular, text, and image datasets.

Pipelines & Architecture

Common Components

  1. Exploratory Data Analysis (EDA)
  2. Preprocessing & feature engineering
  3. Model training & hyperparameter tuning
  4. Evaluation & visualizations

Per-Modal Steps

  • Tabular: Imputation → Scaling → Encoding → Feature Selection.
  • Text: Cleaning → Tokenization → Vectorization (TF-IDF/Embeddings).
  • Images: Feature Extraction (Deep Backbones) → PCA (Optional).

Usage & Setup

How to Run

The project is designed to run on Google Colab or a local Jupyter environment.

Google Colab (Recommended)

  1. Open any notebook from each of the page for the assignment.
  2. Select Runtime → Run all.
  3. The notebook will auto-install dependencies and download data.

Local Environment

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
jupyter notebook
